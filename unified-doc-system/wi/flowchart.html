อ้างอิง

สถานะที่ใช้ในระบบ

เรื่องลำดับสถานะ
คำขอ DAR รออนุมัติคำขอ → อนุมัติให้ดำเนินการ → ดำเนินการแล้ว
หรือ ไม่อนุมัติคำขอ / ยกเลิกคำขอ
เอกสาร รอทบทวน → รออนุมัติ → อนุมัติแล้ว → ยกเลิกใช้
หรือ ไม่ผ่านการทบทวน / ไม่อนุมัติ
รอบตรวจ วางแผน → กำลังตรวจ → รอลงนามสรุปผล → ปิดรอบ
ข้อตรวจพบ เปิด → อยู่ระหว่าง CAPA → ปิด
CAPA เปิด (รอวิเคราะห์สาเหตุ) → กำลังแก้ไข → รอทวนสอบประสิทธิผล → ปิด
